# Taste

## Code organization
- Prefers everything self-contained in a single file (inline CSS and JS inside `index.html`) instead of splitting into separate `css/`, `js/`, and other files; explicitly asks not to add extra files. Confidence: 0.7

## UI / Design
- Prefers data displayed as a clean, orderly table populated with example data rather than an empty table (dislikes the UI looking empty). Confidence: 0.5
- Wants primary-key IDs auto-generated by the backend with the ID field hidden from create forms (no manual typing, ID shown only when editing), and the assigned ID reported back after save. Confidence: 0.55
- Prefers foreign-key references shown as the referenced entity's human-readable name (e.g. the docente's name for a course) rather than exposing the numeric ID. Confidence: 0.5
